# Contributing

Thanks for your interest in DashLens.

## Getting started

1. Fork the repository and create a branch from `main`.
2. Open the project in Android Studio, or build from the command line:
   `./gradlew assembleDebug`
3. Keep changes focused. One fix or feature per pull request.
4. Describe what changed and why in the pull request.

## Guidelines

- Follow the existing Kotlin style in `app/src/main/java/app/dashlens/`.
- Do not commit keystores, tokens, or personal data.
- Report security issues privately, as described in [SECURITY.md](SECURITY.md).

By contributing you agree that your work is released under the [MIT License](LICENSE).
