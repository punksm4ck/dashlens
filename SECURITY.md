# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report privately through GitHub: **Security tab -> Report a vulnerability**
(https://github.com/punksm4ck/dashlens/security/advisories/new).

Include the affected version, steps to reproduce, and the impact you observed.
You can expect an acknowledgement within 7 days.

## Scope

DashLens runs an accessibility service and stores data on-device. Reports about
data exposure, permission misuse, or unintended network access are in scope.
See [docs/PRIVACY.md](docs/PRIVACY.md) for how data is handled.
